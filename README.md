### 🧠 1. AI Industrial Gauge Reader

An embedded AI system designed to read industrial gauge values and resistor color codes using an ESP32-S3 camera system, cloud AI, Telegram alerts, OLED display, and speaker notification.

**What I built**
- ESP32-S3 based embedded system
- OV5640 camera integration for gauge image capture
- Gemini AI API for image-based gauge analysis
- Telegram Bot API for remote command and alert notification
- OLED I2C display for local status output
- I2S speaker warning system for danger alerts
- Resistor color-code calculator through Telegram input

**Engineering focus**

`Embedded Systems` `Edge AI` `Computer Vision` `IoT` `Telegram API` `I2C` `I2S` `HTTPS API`

**Next Development**
- TinyML model deployment on embedded hardware
