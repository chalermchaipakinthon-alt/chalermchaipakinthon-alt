**Built with:** ESP32-S3, OV5640 camera, Embedded C/C++, Gemini API, web interface, Telegram Bot, OLED, I2S audio

**Engineering highlights**

- Integrated local OLED/audio feedback with remote Telegram notifications.

This project is primarily an **embedded and engineering system-integration project** that uses AI as one component of the monitoring workflow.

### [Mini Server Room Monitoring](https://github.com/chalermchaipakinthon-alt/mini-server-room-monitoring)

A personal monitoring project for collecting environmental sensor data, displaying system status, logging events, and sending alerts when abnormal conditions are detected.

**Built with:** ESP32, Python, Flask, HTTP/JSON, web dashboard, Telegram Bot, CSV logging

**Engineering highlights**
- Sends sensor readings from an ESP32 to a Flask server through HTTP/JSON.
- Applies a moving average to reduce sensor noise and improve dashboard readability.
- Uses basic statistical anomaly detection with Z-score and rate-of-change checks.
- Provides dashboard visualization, incident logging, water-leak logic, and Telegram alerts.

I built this project with significant assistance from AI coding tools. My focus is on understanding the overall architecture, system integration, and the basic statistical principles used rather than presenting it as advanced machine learning.
